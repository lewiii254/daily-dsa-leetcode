# 📝 Standard Solution Write-Up Template

Use this at the top of a solution file or in a `problem-name.md` next to it.

## 1) Problem Summary (1–3 lines)
- What is being asked?
- Input/output expectations and constraints (briefly).

## 2) Approach (Plain English)
- High-level strategy.
- Why this approach is preferred over brute force.

## 3) Why It Works
- Key invariant, reasoning, or proof idea.
- What stays true while the algorithm runs.

## 4) Complexity
- **Time:** `O(...)`
- **Space:** `O(...)`

## 5) Common Pitfalls
- Boundary/index errors
- Duplicate handling
- Off-by-one window or pointer movement mistakes

## 6) Example Walkthroughs (1–2)
- Show one standard case.
- Show one edge case.

## 7) Solution
- Clean JavaScript (ES6) implementation.
