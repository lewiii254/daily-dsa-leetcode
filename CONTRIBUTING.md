# 🤝 Contributing to DSA Mastery Kit

Thank you for your interest in contributing! This project aims to help thousands of developers master DSA and land their dream jobs.

---

## 📋 How to Contribute

### 1. Fork & Clone
```bash
git clone https://github.com/YOUR_USERNAME/daily-dsa-leetcode.git
cd daily-dsa-leetcode
```

### 2. Create a Branch
```bash
git checkout -b feature/add-binary-search-problem
```

### 3. Add Your Content

Follow the **problem format** strictly:

```markdown
## Problem Name

### 🧩 Problem
Problem statement here...

### 💡 Intuition
Explain your thinking...

### ⚡ Solution (JavaScript)
// Clean, well-commented code

### ⏱ Complexity
- **Time:** O(n)
- **Space:** O(1)

### 🔁 Variations
- Related Problem 1
- Related Problem 2
```

### 4. Submit a Pull Request
- Write a clear PR title: `Add: [Problem Name] in [Section]`
- Describe what you added
- Link to source if it's from LeetCode/Codility

---

## ✅ Contribution Checklist

- [ ] Problem follows the standard format
- [ ] Code is in JavaScript (ES6)
- [ ] Code is well-commented
- [ ] Complexity analysis is included
- [ ] No duplicate problems (check existing files)
- [ ] README updated if adding new topic

---

## 📌 What We Accept

✅ New problems with full explanations
✅ Better solutions to existing problems
✅ Bug fixes in existing solutions
✅ Improved explanations or documentation
✅ New real-world problem examples

---

## ❌ What We Don't Accept

❌ Solutions without explanations
❌ Empty files or placeholder content
❌ Solutions in languages other than JavaScript (for now)
❌ Problems without complexity analysis
