# 📝 Mock Test 2 — 90 Minutes

**Intermediate level.** Focus on trees, dynamic programming, and sliding window.

---

## Problem 1 — Climbing Stairs (Easy, 10 min)
How many ways to climb n=5 stairs taking 1 or 2 steps at a time?

## Problem 2 — Invert Binary Tree (Easy, 15 min)
Mirror a binary tree left-right in-place.

## Problem 3 — Longest Substring Without Repeating (Medium, 20 min)
Find length of longest substring without repeating characters in `"abcabcbb"`.

## Problem 4 — Coin Change (Medium, 25 min)
Minimum coins from `[1,5,6,9]` to make amount `11`.

## Problem 5 — Number of Islands (Medium, 25 min)
Count connected components of '1's in a 2D grid (BFS/DFS).
