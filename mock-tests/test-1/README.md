# 📝 Mock Test 1 — 90 Minutes

**Rules:** No external help. Solve all 5 problems. Analyze complexity for each.

---

## Problem 1 — Two Sum (Easy, 10 min)
Given `nums = [2,7,11,15]` and `target = 9`, return indices of the two numbers.

## Problem 2 — Valid Parentheses (Easy, 10 min)
Return true if the bracket string is valid: `"({[]})"`.

## Problem 3 — Maximum Subarray (Medium, 20 min)
Find contiguous subarray with largest sum: `[-2,1,-3,4,-1,2,1,-5,4]`.

## Problem 4 — Merge Two Sorted Lists (Medium, 20 min)
Merge `[1,2,4]` and `[1,3,4]` into one sorted linked list.

## Problem 5 — Binary Search (Medium, 15 min)
Search for target in sorted array. Return index or -1.
