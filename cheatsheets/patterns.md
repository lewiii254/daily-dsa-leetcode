# 🗺 DSA Patterns Cheatsheet

| Pattern | When to Use | Complexity |
|---------|-------------|------------|
| Two Pointers | Sorted array pairs/triplets | O(n) |
| Sliding Window | Contiguous subarray/substring | O(n) |
| Prefix Sum | Range sum queries | O(1) query |
| Fast-Slow Pointers | Cycle detection, middle node | O(n) |
| Binary Search | Sorted/monotone search space | O(log n) |
| BFS | Shortest path, level-order | O(V+E) |
| DFS / Backtracking | All paths, permutations | O(2^n) |
| Dynamic Programming | Overlapping subproblems | Varies |
| Greedy | Local optimal = global optimal | O(n log n) |
| Monotonic Stack | Next greater/smaller element | O(n) |
| Heap / Priority Queue | K-th largest, top K | O(n log k) |
| HashMap | Frequency count, lookup | O(n) |
