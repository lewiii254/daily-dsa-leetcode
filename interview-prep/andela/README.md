# 🌍 Andela Interview Prep

Andela evaluates technical excellence, problem-solving approach, and code quality.

## Interview Stages
1. **Online Assessment** — Algorithmic coding test (90 min)
2. **Technical Interview** — Live coding + problem discussion
3. **System Design** — Architecture and scalability
4. **Values Interview** — Cultural fit

## What Andela Looks For
- Clean, readable code
- Optimal solutions with complexity analysis
- Good communication while solving
- Testing mindset
