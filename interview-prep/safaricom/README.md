# 🦁 Safaricom Interview Prep

Safaricom (Kenya) technical interviews focus on practical problem-solving, data structures, and real-world system design.

## What to Expect
- Coding challenges (1–2 hours)
- System design questions (M-Pesa scale)
- SQL and API design questions
- JavaScript / Python proficiency

## Key Topics
- String manipulation, arrays, HashMaps
- REST API design
- Database query optimization
- M-Pesa transaction flows
