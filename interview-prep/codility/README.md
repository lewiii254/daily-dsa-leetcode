# 🎯 Codility Interview Prep

Codility tests algorithmic thinking under time pressure. Each task is scored 0–100 based on correctness and performance.

## Scoring
- **Correctness:** Do all test cases pass?
- **Performance:** Does it meet the required time complexity?

## Tips
- Read constraints carefully — they hint at required complexity
- O(n) or O(n log n) is usually expected
- Handle edge cases: empty arrays, n=1, max values
- Test with given examples before submitting
